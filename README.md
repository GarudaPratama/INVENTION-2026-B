# Gizify

## Deskripsi

Gizify adalah platform digital yang menyediakan informasi dan fitur seputar gizi, makanan, dan gaya hidup berkelanjutan.

## Fitur Utama

* **BMI & BMR** — Menghitung indeks massa tubuh dan perkiraan kebutuhan energi dasar.
* **TDEE** — Menghitung perkiraan total kebutuhan energi harian berdasarkan aktivitas pengguna.
* **Artikel** — Menyediakan berbagai informasi seputar gizi, makanan, dan gaya hidup sehat.
* **Nutrition Finder** — Membantu menemukan tempat atau fasilitas yang berkaitan dengan pangan dan gizi di sekitar pengguna.

## Teknologi yang Digunakan

* HTML
* Tailwind CSS
* JavaScript
* jQuery

## Cara Menjalankan Project

1. Clone repository ini.
2. Buka folder project.
3. Jalankan file `index.html` menggunakan browser.
